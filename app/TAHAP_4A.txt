TAHAP 4A — PROFIL: POSTINGAN, SAVED, PROFIL ORANG LAIN
=======================================================

ISI TAHAP INI (mengikuti gambaran desain profil)
- Tab Profil (nomor 5) sekarang layar asli, menggantikan stub:
  avatar besar, @username, "Bergabung <tanggal>", tiga aksi (Set Photo, Edit Info, Settings),
  baris Jurusan dan Bio, lalu tab: Postingan | Market | Saved.
- Postingan: daftar postinganmu (termasuk yang anonim; anonim hanya terlihat olehmu),
  terbaru dulu, paginasi saat digulir, tarik untuk muat ulang.
  Kartunya sama dengan Home: upvote/downvote, simpan, bagikan, menu (ubah/selesai/hapus), buka detail.
- Saved: postingan yang kamu simpan, simpanan terbaru dulu. Batal simpan = hilang dari daftar.
- Market: keterangan sementara (isi menyusul bersama fitur Market).
- Profil orang lain: ketuk avatar/nama penulis di Home, Detail, atau daftar profil.
  Tampil tanpa aksi ubah dan tanpa Saved; hanya postingan yang tidak anonim.
  Ikon bendera di atas = Laporkan pengguna (memakai sheet laporan yang sama).
- Settings: sementara hanya "Keluar" (dengan konfirmasi). Set Photo / Edit Info menampilkan
  "hadir di Tahap 4B". Pengaturan akun lengkap, ubah profil, ganti foto, hapus akun = Tahap 4B.

CHECKLIST TES MANUAL
1. Masuk (OTP 123456), buka tab Profil: header sesuai data akunmu; Jurusan "Belum diisi" bila kosong.
2. Tab Postingan menampilkan postingan milikmu. Buat postingan baru dari Home -> muncul di profil
   (tarik layar ke bawah untuk memuat ulang).
3. Postingan anonim milikmu tampil di profilmu sebagai "Anonim", tapi tidak di profil orang lain.
4. Vote pada postingan sendiri -> pesan tidak bisa. Hapus/selesaikan lewat titik tiga -> daftar ikut berubah.
5. Simpan postingan di Home/Profil -> tab Saved berisi; batal simpan dari Saved -> hilang dari daftar.
6. Tab Market -> keterangan "Belum ada produk".
7. Di Home ketuk avatar/nama penulis (mis. dina_kamila) -> profilnya terbuka dengan tombol kembali.
   Tidak ada Set Photo/Edit Info/Saved. Ketuk postingan di sana -> detail terbuka, kembali -> profil tetap.
8. Postingan anonim: ketuk nama "Anonim" -> tidak terjadi apa-apa.
9. Ikon bendera di profil orang lain -> pilih alasan -> terkirim.
10. Settings -> Keluar -> konfirmasi -> kembali ke layar login.
11. Edit Info / Set Photo -> muncul keterangan "hadir di Tahap 4B".
